# Zentrale Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** ADHS-Kommandozentrale als PWA unter `zentrale/` (Jetzt, Woche, 5 Bereiche, Berg zerlegen, Backup).

**Architecture:** Vanilla HTML/CSS/JS ohne Build, wie `praxis/`. Reine Logik in `logic.js` (Browser-Global `Logic` und Node-Export), UI in `app.js`. Daten in `localStorage['zentrale-v1']`.

**Tech Stack:** HTML/CSS/JS, `node --test` für Logik-Tests.

**Spec:** `docs/superpowers/specs/2026-11-23-zentrale-design.md`

## Global Constraints

- Deutsch, kein Build-Schritt, nur lokale Daten, Import führt zusammen (überschreibt nicht).
- Bereiche: `uni`, `arbeit`, `privat`, `partei`, `adhs`. Mo und Do = Dresden-Sommer-Tage.
- Keine Strafen/Streaks. Erfassen in einem Feld + Enter.

## Review Focus

- Aufgabe ohne Schritte und ohne Frist → trotzdem „Jetzt"-Karte mit Hinweis „Zerlegen".
- Monatliche Frist am 31. → springt auf Monatsende (28./30.), nicht in den Folgemonat.
- Leere Daten / alles erledigt → freundlicher Leerzustand, kein Fehler.
- Import einer kaputten Datei → Meldung, bestehende Daten bleiben.
- Aufgabentitel mit `<script>` → wird escaped angezeigt.

### Task 1: Logik (`zentrale/logic.js`, `zentrale/test/logic.test.js`)

**Interfaces — Produces:**
- `rank(tasks, today, skip?) -> Task[]` offene Aufgaben nach Regel: überfällig, nächste Frist, „doing", älteste.
- `pickNext(tasks, today, skip?) -> {task, step|null, reason} | null`
- `nextDue(due, repeat) -> iso` (`weekly`|`monthly`, Monatsende-Klemmung)
- `weekDays(today) -> iso[7]` Mo–So
- `dueLabel(due, today) -> string`
- `mergeData(local, incoming) -> data` je `id`, neueres `updatedAt` gewinnt
